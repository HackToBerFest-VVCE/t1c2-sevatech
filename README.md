# SevaTech – Bridging Services

## About the Project
SevaTech aims to improve coordination between Anganwadi
workers, ASHA workers, parents, and government authorities
through a centralized digital platform.

## Key Modules

### PoshanNet AI
- Child nutrition tracking
- Growth data management
- Nutrition insights

### MatruMitra
- Maternal health records
- Pregnancy monitoring
- Health reminders

## Key Features
- Centralized data management
- Web and mobile dashboard
- AI-based analytics and alerts
- Role-based access
- Improved service coordination

## Target Users
- Anganwadi Workers
- ASHA Workers
- Parents
- Government Authorities

Initial project documentation and development planning.
